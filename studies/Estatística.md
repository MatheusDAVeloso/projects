Média
É a soma dos valores de um conjunto dividido pela sua quantidade

Média Ponderada
É a soma dos valores de um conjunto, sendo cada valor multiplicado por seu peso, e dividido pela soma dos pesos

Mediana
É o termo central dos valores de um conjunto em ordem crescente.
- Quando é ímpar, é o termo do meio
- Quando é par, é os dois termos centrais dividido por 2 (ou a média dos termos centrais)

Moda
É o elemento que mais se repetiu em um conjunto
- Amodal é quando nenhum valor se repetiu
- Moda do conjunto é o elemento que mais se repetiu
- Bimodal é quando dois elementos do conjunto mais se repetiram, porém empataram
- Trimodal é quando três elementos do conjunto mais se repetiram, porém empataram
