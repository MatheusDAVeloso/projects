# O que é este repositório
Este é um repositório onde tento acompanhar minha sede de conhecimento em informática, colocando todo dia um novo esforço.

## O que ele contém
Este repositório agrupa um visualizador em forma de árvore de diretórios escrito em `C`, o famoso triângulo colorido desenhado com `OpenGL` e `C` e estudos sobre diferentes tópicos.
