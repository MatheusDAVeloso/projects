Quando um arquivo de instruções escritas em uma linguagem de programação é executado, por exemplo: 

```C
#include <stdio.h>
int a = 5 + 5;
printf("Result: %i", a);
```

O arquivo sai do disco rígido e vai para a memória ram, virando um programa. E a ULA no processador é responsável por fazer as operações matemáticas utilizando contas binárias. Todo esse processo — além do output no terminal — o [[Compilação|compilador]] solicita ao [[Sistemas Operacionais|sistema operacional]] esta ação.
